# 资产规格 — Tactical Mech Helmet / 战术机甲头盔

## 一、资产定位

一件作品集级硬表面道具练习，题材为科幻战术机甲头盔。目标不是还原任何现有 IP，
而是借这个题材把硬表面建模里最常被检查的几件事完整走一遍：结构转折、倒角、
铆钉与螺丝细节、磨砂与拉丝金属拼接、PBR 材质、工作室布光、以及可复核的拓扑与 UV。

全程原创建模，没有复制任何商用模型或贴图。造型语言参考的是通用工业设计常识
（装甲分块、散热格栅、液压连杆、密封条），这些属于通用技法范畴。

## 五、灯光与相机

- 三点式工作室布光：主光（大面积柔光箱）、冷色补光、背部轮廓光，另加顶光与橙色点缀光。
- 背景：程序化垂直渐变（深灰），无地板几何体，避免边缘穿帮。
- 相机：三分之四视角，62mm→55mm 定焦，无景深，保证结构处处清晰。
- 色彩管理：AgX + Medium High Contrast。
